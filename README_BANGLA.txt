=== BCS ফ্লিপ স্টাডি v2 (ধাপ ১ + ২ + ৩ + ৪ সম্পন্ন) ===

নতুন আপগ্রেডসমূহ:
1. ব্যাটারি কোর (ধাপ ১): কোনো WakeLock নেই, প্রতি সেকেন্ডের ব্যাকগ্রাউন্ড টিক নেই! Wake-up Accelerometer (৫ সে. ব্যাচিং + ২.৫ সে. ডিবউন্স), AlarmManager.setAlarmClock(), সিস্টেম Chronometer কাউন্টডাউন, এবং প্রসেস মারা গেলেও অবস্থা ধরে রাখার সুরক্ষা।
2. ডেটা ও সিঙ্ক (ধাপ ২): লোকাল ডেটা কখনোই মুছবে না; কেবল synced=false দিনগুলো সিঙ্ক হবে এবং সার্ভার {"ok":true} দিলেই synced=true হবে। বিষয় ও অপচয়ের কারণের বিস্তারিত ম্যাপ (subjects, wasteReasons) যুক্ত হয়েছে।
3. মাসিক ও বার্ষিক রিপোর্ট (ধাপ ৪): ◀ মাস ▶ নেভিগেশন, মাসিক/বার্ষিক টগল, স্ট্রিক, প্রোডাক্টিভিটি স্কোর, ফ্লেক্সিবল বার চার্ট, ক্যাশ ও অফলাইন ফলব্যাক।

ইনস্টল ও সেটআপ:
- পুরোনো অ্যাপ আনইনস্টল না করেই নতুন APK তার উপরে ইনস্টল করো (পুরোনো ডেটা অটো-মাইগ্রেট হবে)।
- Apps Script-এ নতুন Code.gs বসিয়ে Deploy -> Manage deployments -> Edit -> New version -> Deploy দাও।
- গোপন কী দিতে চাইলে Apps Script-এ Project Settings -> Script Properties -> Add property: SYNC_KEY = (তোমার পছন্দমতো পাসওয়ার্ড), এবং অ্যাপের সেটিংসেও একই কী বসাও।
